
# Student Management System

A console-based Student Management System developed using C++ and SQLite.

## Features

1. Add Student
2. View All Students
3. Search Student by Roll Number or Name
4. Update Student Details
5. Delete Student
6. Sort Students by Marks
7. Display Topper Student
8. Count Total Students
9. Calculate Average Marks
10. Display Top 3 Students
11. Search Student by ID
12. Input Validation

## Technologies Used

- C++
- SQLite Database
- Git and GitHub
- GitHub Codespaces

## How to Compile and Run

**Compile:**
```bash
g++ main.cpp -o student_app -lsqlite3
```

**Run:**
```bash
./student_app
```

## Database

SQLite is used to store student records permanently.
